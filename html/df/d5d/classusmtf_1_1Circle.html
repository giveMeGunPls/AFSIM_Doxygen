Detailed Description

The Circle Set is used to provide a single position with a radius specifying width.

Example: CIRCLE/LATS:203632N0594256E/15NM//

USMTF Standard Excerpt: CIRCLE/ / // 1 CENTER OF CIRCLE 2 RADIUS IN NAUTICAL MILES, METERS, OR KILOMETERS

Detailed Document: CIRCLE.UF.RTF
