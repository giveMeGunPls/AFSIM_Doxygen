Detailed Description

Two-component Julian TDB Date

The NOVAS routines obtain their highest precision when using a Julian date given by a whole part and a fractional part. Per the documentation in eph_manager.cpp: for maximum interpolation accuracy, set the first component to the most recent midnight at or before the interpolation epoch, and set the second component to be the fraction of a day since then.
