template<typename T>
void wsf::comm::ScriptNetworkClass::DestroyHelper ( void * aNetworkPtr)
inlinestaticprotected

Typically, network objects are expected to be added to the simulation's network manager for handling any allocated memory. However, this may not be ultimately the case, and as such, we would have a memory leak. The DestroyHelper method will validate the network object has not been transferred ownership to the network manager before deleting for correct management of allocated memory of network objects.
