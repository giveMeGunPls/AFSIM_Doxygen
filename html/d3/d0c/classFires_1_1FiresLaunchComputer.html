Detailed Description

A launch computer for use with weapons employing the WSF_FIRES_MOVER type. This class stores the fires tables of range, max. ord. (max. height), and time of flight, for classes of Systems + Munitions. If a weapon uses this launch computer, the fired munition will automatically call "GetMaxOrdAndTOF" to initialize itself.
