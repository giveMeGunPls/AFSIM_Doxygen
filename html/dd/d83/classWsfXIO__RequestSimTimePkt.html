enum WsfXIO_RequestSimTimePkt::TimerType : std::uint16_t
Enumerator
cSIM_TIME_INTERVAL 

Specifies receipt of updates based on a simulation time interval 1.0 s interval / 10x clock rate = 10 updates per second

cADJUSTED_SIM_TIME_INTERVAL 

Specifies receipt of updates based on a simulation time interval adjusted by clock rate 1.0 s interval / 10x clock rate = 1 update per second

cNO_TIME_INTERVAL 

Specifies receipt of updates only when switching simulation state.

cREAL_TIME_INTERVAL 

Specifies that the interval is in real-time seconds. Useful for obtaining intermittent sim time updates.
