24// The AeroCoreObject provides the main aerodynamics for an object.
25// It includes various aero parameters and stability derivatives. It may
26// include one or more aero modes, which provide configuration-dependent aero.
27// Modes also provide a means to remove any aero effects, such as while a subobject
28// is internally carried. A different mode can then be used when 'free'.
