Detailed Description

The wsf standard implementation of WsfFusionStratgey for track fusion. This class implements a series of standard algorithms for fusion of similar and complementary information. The one option for use of these algorithms is whether to use "replacement" or "weighted average" fusion. These choices are relevant when fusing location-based state data. For replacement fusion, a track update replaces the location data, whereas for weighted-average fusion, the location data are computed using the "weight" of the inverse covariance matrix.
