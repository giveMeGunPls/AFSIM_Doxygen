Detailed Description

template<class T>
class WsfComponentList::RoleIterator< T >

An iterator that provides sequential access to components that support a specific role. Usage:

for (WsfComponentList<T>::RoleIterator<WsfProcessor> iter(componentList); ! iter.AtEnd(); ++iter)
{
WsfProcessor* proc = *iter; // this or ...
iter->MethodOnProcessor(...); // ... this
...
}
