Detailed Description

A nested class containing information needed to keep track of implicit engagements. These can be either based on truth target name and offset, or track data and offset (the offset need not be specified). The engagement pointer is stored, along with the engagement id and a flag indicating whether we've set up an event to terminate the engagement.
