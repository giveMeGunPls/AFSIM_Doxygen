Detailed Description

The Mode class represents a functional state of a medium. Each medium can be made up of one or more Mode objects that allow the medium to change its behavior depending on the mode selected. This allows for unique handling of each message dependent on user defined criteria (e.g. the recipient, distance, channel utilization, etc.)
