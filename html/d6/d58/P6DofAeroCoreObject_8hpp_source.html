25// The P6DofAeroCoreObject provides the main aerodynamics for an object.
26// It includes various aero parameters and stability derivatives. It may
27// include one or more aero modes, which provide configuration-dependent aero.
28// Modes also provide a means to remove any aero effects, such as while a subobject
29// is internally carried. A different mode can then be used when 'free'.
