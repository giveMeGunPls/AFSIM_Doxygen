Define a WSF type corresponding with a given UCI type. The WSF type can be constructed and destructed without direct reference to the abstract bus. Arguments: WSF_TYPE : The name of the WSF type to be defined. UCI_TYPE : The name of the existing UCI type. ACCESSOR_NAME : The accessor id corresponding with the existing UCI type (from uci::type::accessorType).

For example, the following definition:

DEFINE_UCI_TYPE(UCI_CapabilityID_Type, CapabilityID_Type, capabilityID_Type)
