Detailed Description

A types factory of wsf::TrackExtrapolationStrategy types.

Note
Currently only the default strategy is used by the core (see WsfMeasurement::GetTrackExtrapolators). However, this capability could eventually be used to configure individual trackers with a specific strategy.
