Detailed Description

template<typename T, typename SERVICE_TYPE = WsfXIO_Service>
class WsfXIO_ServiceT< T, SERVICE_TYPE >

Provides extended functionality for handling WsfXIO_Requests Ties a subscription to the original request for that subscription. Template parameter 'T' is the request packet used for this subscription provider and must be derived from WsfXIO_SubscriptionRequestPkt.
