Detailed Description

This is a pseudo-6DOF (MRM) mover. It includes 6 degrees-of-freedom, but includes a heavily simplified rotation kinematics model. This model provides many 6DOF capabilities but is easier to use, easier to understand, and executes faster than the rigid-body 6DOF model.
