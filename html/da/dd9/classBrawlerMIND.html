Detailed Description

Reads in and provides access to values from the BRAWLER MIND file

Member variables names differ from the standard on purpose to match the names used in BRAWLER. Access methods are given a more descriptive name. See section 3.2.5 of the BRAWLER User Manual for more information on values.
