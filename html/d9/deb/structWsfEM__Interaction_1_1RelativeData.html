Detailed Description

Represents the relative location of one object with respect to another.

Note
The azimuth and elevation angle are with respect to the CUED orientation of the source object.
This data may not be valid if the Begin<>Interaction methods returned early due to a failed constraint check (they exit as soon as possible to eliminate unnecessary computations). Observers using this data (e.g.: WsfEventOutput) should call ComputeUndefinedGeometry prior to using this data.
