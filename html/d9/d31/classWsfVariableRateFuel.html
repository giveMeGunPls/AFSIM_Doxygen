Detailed Description

Fuel consumption rate model.

This class defines fuel consumption behavior, at either constant rates, or at variable rates based upon one or two independent variables (the choices are platform altitude and speed). By default, one fuel table is accepted, independent of fuel mode. However, multiple tables may be defined for different fuel modes, if supplied, and the active table will be switched by setting the fuel mode. (This model differs from the similar WsfTabularRateFuel in that the table input format is more flexible, and need not be rectangular.)
